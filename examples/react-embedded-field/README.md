# Example: React Embedded Field Editor

Demonstrates using `ContentFieldEditor` from `@allebrum/page-editor` for compact content areas.

## Use cases

- Event descriptions
- Profile bios
- Announcement text
- Card content
- FAQ item answers
- Service descriptions

## What this shows

- `ContentFieldEditor` with allowed block restrictions
- Autosave with status indicator
- Min/max height constraints
- AI writing tools in embedded mode
